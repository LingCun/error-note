# 에러노트

에러 로그와 발생 상황을 한국어 개발 이슈 카드로 정리하는 작은 웹 앱입니다.

## 기능

- 가입 없이 브라우저 안에서 규칙 기반 정리
- 이메일, 전화번호, Bearer, JWT, 흔한 API 키와 비밀번호 패턴 가리기
- 사실과 원인 후보 구분, 확인 순서와 공유 질문 작성
- Markdown 복사 및 파일 다운로드
- 선택적으로 Vercel AI Gateway를 통한 AI 분석
- 입력 내용은 앱 DB나 브라우저 저장소에 저장하지 않음

## 실행

Node.js 22 이상이 필요합니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:3000 에서 실행합니다. `npm test`, `npm run check`로 검증합니다.

## Vercel 배포

GitHub 저장소를 Vercel에서 Import합니다. Framework Preset은 Other, Output Directory는 `public`입니다. `/api/analyze.js`는 Vercel Function입니다. Git 연결 후 main 브랜치 푸시는 자동 배포됩니다.

기본 정리는 AI 자격증명 없이 동작합니다. AI는 다음 환경변수를 설정한 뒤 재배포하면 활성화됩니다.

| 변수 | 설명 |
| --- | --- |
| AI_ENABLED | 활성화 시 `true`, 기본 비활성 |
| AI_GATEWAY_MODEL | 공식 모델 목록에서 선택한 `provider/model` ID |
| AI_GATEWAY_API_KEY | 로컬 실행용. Vercel 배포에서는 OIDC 사용 가능 |

2026-10-23 모델 목록에서 텍스트 분석용 `google/gemini-3.8-flash`가 확인됐습니다. 활성화 전에 현재 모델 지원 여부와 요금을 확인하세요. 환경변수는 Vercel 설정에 입력하고, 비밀값을 소스·채팅·Git에 넣지 마세요.

이 프로젝트는 공개 AI 호출로 인한 예상치 못한 비용을 피하도록 AI를 기본 비활성화합니다. AI Gateway 인증·크레딧·프로젝트 예산을 설정한 다음 활성화하세요. 서버의 인스턴스별 1분 제한은 보조 수단이며 분산 환경 전체의 비용 상한이 아닙니다. 공개 AI 서비스를 확장할 때는 영속적인 사용량 제한과 인증을 추가하세요.

## 개인정보와 한계

기본 정리는 브라우저 안에서 실행됩니다. AI를 선택하면 서버에서 다시 가린 로그·상황·환경을 Vercel AI Gateway와 모델 제공자에 전송합니다. 외부 서비스의 기록·보관 정책은 별도로 적용됩니다. 패턴 기반 가리기는 모든 민감정보를 탐지하지 못합니다. 전송 및 공유 전 내용을 검토하세요.

규칙 기반 결과와 AI 결과 모두 원인 확정이 아닙니다. 자동 저장·공개 공유 링크·로그 수집 기능은 없습니다.
